# YouTube To DVD

[![License: MIT](https://img.shields.io/badge/License-MIT-brightgreen?style=flat-square)](/LICENSE)

指定されたYouTubeの動画をDVDに焼くためのツールです。
ご利用の前に[利用上の注意](#利用上の注意)をお読みください。

---

## インストール

### Golang環境が存在している場合

```sh
go install github.com/aethiopicuschan/youtube2dvd@latest
```

### Golang環境が存在しない場合

[リリースページ](https://github.com/aethiopicuschan/youtube2dvd/releases)から環境に合わせたバイナリをダウンロードしてください。

## 使い方

### DVDに書き込みたい場合

以下が必要です。

- インターネット環境
- DVD書き込み対応のドライブ
- 書き込み可能なDVDディスク

「ダウンロード」タブから動画を保存し、「書き込み」タブで動画をダブルクリックしてキューに追加します。書き込み方法を選ぶボタンを押し、DVDメニューのタイトルを入力して「DVDに書き込む」を選択してください。ダウンロード済みフォルダにある動画もキューに追加できます。

DVDへの書き込みは、アプリが対応ドライブと書き込み可能なディスクを検出した場合に利用できます。OSごとに次の書き込み機能を使います。

- macOS: 標準の`drutil`
- Windows: Windows標準のIMAPI2
- Linux: `growisofs`（`dvd+rw-tools`パッケージに含まれます）

### ISOファイルを作成したい場合

YouTube動画を取得する場合はインターネット環境が必要です。ダウンロード済みの動画から作成する場合は不要です。書き込み方法を選ぶボタンを押し、DVDメニューのタイトルを入力して「ISOファイルとして保存する」を選択してください。

## 高画質でダウンロードしたい場合（任意）

本ツール内蔵のダウンロード機能で取得できる画質は、多くの場合 360p までです。外部ツールの [yt-dlp](https://github.com/yt-dlp/yt-dlp) を別途インストールし、本ツールの「設定」で「外部の yt-dlp を使ってダウンロードする」を有効にすると、yt-dlp を使って 480p までの画質でダウンロードできます。

- 本ツールは yt-dlp を同梱・配布していません。インストール方法は [yt-dlp 公式の案内](https://github.com/yt-dlp/yt-dlp)を参照してください。
- チェックを入れると、よく使われるインストール先から yt-dlp を自動で探し、実行できることを確かめてから使います。見つからない場合は、yt-dlp をインストールしてからもう一度チェックを入れてください。
- 「クッキー」の右の鉛筆ボタンから Netscape 形式の cookies.txt を選ぶと、yt-dlp の実行時に `--cookies` で渡します。yt-dlp はこのファイルに受け取ったクッキーを書き戻します。
- yt-dlp を利用する場合にも、下記の「利用上の注意」が同様に当てはまります。

## 字幕と音声

- 字幕がある動画では、「字幕」で規定の言語を、「追加の字幕」でほかの言語を選び、動画のファイル（MP4/WebM）に入れて保存できます。DVDにも字幕として入り、「字幕」で選んだ言語が最初に表示されます。プレーヤーの字幕ボタンで切り替えや非表示ができます。
- 吹き替えなどで複数の言語の音声がある動画では、yt-dlp を使っている場合に「音声」で規定の言語を、「追加の音声」でほかの言語を選べます。DVDには選んだ音声がすべて入り、「音声」で選んだ言語が最初に流れます。プレーヤーの音声ボタンで切り替えられます。

## 補足

ダウンロードされた動画は、OSのダウンロードフォルダ内の `youtube2dvd` フォルダに保存されます。フォルダがない場合は自動で作成されます。同じ名前のファイルがある場合は上書きせず、ファイル名に連番を付けて保存します。
したがって、同フォルダに手動で動画ファイルを追加することによっても、このツールで扱うことができます。ただし、対応しているフォーマットはMP4とWebMのみです。

DVDメニューには、入力したタイトルと、各動画のファイル名（拡張子を除く）が表示されます。どちらも日本語に対応しています。半角の英字は大文字で表示され、絵文字や機種依存文字など一部の文字は「?」になります。
